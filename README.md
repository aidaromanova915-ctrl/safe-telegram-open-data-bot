# Бесплатный безопасный Telegram-бот: домены и публичные IP

Бот показывает DNS-адреса домена и базовую общедоступную справку о публичных IP. Он не ищет частных лиц, телефоны, документы, аккаунты или данные из утечек и не выполняет сканирование портов.

## Запуск локально

1. Создайте бота через [@BotFather](https://t.me/BotFather), выполнив `/newbot`, и скопируйте выданный API-токен. Имя `@find61b7yb0_bot` — это username, а не токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен после `BOT_TOKEN=`. Не публикуйте токен и не добавляйте `.env` в Git.
3. Установите Python 3.10+ и зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
   pip install -r requirements.txt
   ```

4. Установите переменную окружения и запустите:

   ```bash
   export BOT_TOKEN="ваш-токен"  # PowerShell: $env:BOT_TOKEN="ваш-токен"
   python bot.py
   ```

Бот бесплатный; для работы нужен запущенный компьютер/сервер и интернет. Telegram-боты не работают, пока программа не запущена. Для постоянной работы может потребоваться хостинг, который не всегда бесплатен.

## Приватность

Бот не сохраняет запросы или профиль. Ограничение частоты запросов временное, хранится в памяти и сбрасывается при остановке. Для справочной информации о публичных IP используется сторонний сервис ipwho.is; введённый IP передаётся ему. Не вводите секреты или персональные данные.
